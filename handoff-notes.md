## What I delivered
The page is a basic support portal page where you can contact support to request assistance.

## How I verified the page

## Remote change I received
Remote teammate made change to main by adding a support escalation message to the README. Used git pull to get changes from github to ensure all team members have the same main to work from.

## Git workflow explanation
Git commit alone can not update Github since it would need staged changes to commit. You must stage your changes first before you can commit them, using the git add command.
